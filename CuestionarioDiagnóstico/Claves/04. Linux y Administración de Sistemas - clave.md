# 04. Linux y Administración de Sistemas — Clave

Consulta esta clave después de responder el módulo completo.

## Nivel 1 — Esencial

### LNX-E1 — A

**Evalúa:** Diferencia entre rutas absolutas y relativas.

**Explicación:** Una ruta que comienza en `/` se interpreta desde la raíz y no depende del directorio de trabajo actual.

### LNX-E2 — C

**Evalúa:** Lectura de permisos básicos.

**Explicación:** En `640`, el propietario tiene lectura y escritura, el grupo solo lectura y otros ningún permiso.

### LNX-E3 — B

**Evalúa:** Concepto de proceso.

**Explicación:** Un programa es código almacenado; al ejecutarlo se crea un proceso con memoria, identificador y otros recursos.

### LNX-E4 — B

**Evalúa:** Flujos estándar de un proceso.

**Explicación:** La separación permite enviar la salida útil a un archivo o tubería y conservar los errores en otro destino.

### LNX-E5 — A

**Evalúa:** Principio de mínimo privilegio.

**Explicación:** Trabajar con los permisos necesarios reduce el daño posible de una equivocación o una aplicación comprometida.

## Nivel 2 — Aplicado

### LNX-A1 — C

**Evalúa:** Método inicial de diagnóstico de servicios.

**Explicación:** El estado y los registros entregan evidencia del fallo; validar la configuración evita introducir cambios adicionales sin fundamento.

### LNX-A2 — A

**Evalúa:** Diagnóstico inicial de recursos.

**Explicación:** Medir CPU, memoria, disco, red y procesos permite localizar el recurso limitante y comprobar después si un cambio realmente ayudó.

### LNX-A3 — C

**Evalúa:** Expansión segura de rutas en shell.

**Explicación:** Las comillas evitan dividir una ruta con espacios y `--` indica que los argumentos posteriores no deben interpretarse como opciones.

### LNX-A4 — B

**Evalúa:** Diagnóstico básico de conectividad de servicios.

**Explicación:** Confirmar dónde escucha el proceso y revisar la ruta de red permite distinguir un problema de aplicación, enlace o filtrado.

### LNX-A5 — B

**Evalúa:** Diferencias entre entornos interactivos y programados.

**Explicación:** Las tareas programadas no deben depender de perfiles personales; sus rutas y configuraciones deben quedar declaradas explícitamente.

## Nivel 3 — Profundización

### LNX-P1 — C

**Evalúa:** Permisos heredables en directorios compartidos.

**Explicación:** `setgid` conserva el grupo del directorio y una ACL predeterminada aplica permisos acordados a los elementos nuevos.

### LNX-P2 — A

**Evalúa:** Terminación controlada de procesos.

**Explicación:** La señal normal ofrece tiempo para limpiar estado y subprocesos; una terminación forzada queda como último recurso tras un límite definido.

### LNX-P3 — B

**Evalúa:** Despliegue y reversión atómicos.

**Explicación:** Cambiar un enlace simbólico preparado evita copiar una versión parcialmente y permite regresar apuntando nuevamente a la anterior.

### LNX-P4 — C

**Evalúa:** Observabilidad entre procesos y réplicas.

**Explicación:** Los IDs de traza, tramo o intento relacionan eventos entre réplicas. Una secuencia o tiempo sincronizado ayuda a reconstruir su orden.

### LNX-P5 — A

**Evalúa:** Manejo seguro de nombres de archivo en lotes.

**Explicación:** La delimitación nula conserva espacios y saltos de línea. `--` o un prefijo seguro evita que una ruta iniciada en `-` se interprete como opción.
