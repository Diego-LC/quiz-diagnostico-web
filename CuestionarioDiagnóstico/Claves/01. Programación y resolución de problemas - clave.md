# 01. Programación y resolución de problemas — Clave

Consulta esta clave después de responder el módulo completo.

## Nivel 1 — Esencial

### PRO-E1 — B

**Evalúa:** Comprensión del concepto de algoritmo.

**Explicación:** Un algoritmo describe pasos ordenados, finitos y ejecutables para transformar entradas en un resultado.

### PRO-E2 — C

**Evalúa:** Uso de estructuras condicionales.

**Explicación:** Una condición permite escoger qué bloque ejecutar según el resultado verdadero o falso de una expresión.

### PRO-E3 — A

**Evalúa:** Descomposición de un programa en funciones.

**Explicación:** Las funciones con una tarea clara facilitan la reutilización, las pruebas y la comprensión del código.

### PRO-E4 — B

**Evalúa:** Selección de una estructura repetitiva.

**Explicación:** Un ciclo permite visitar cada calificación y aplicar la misma evaluación a todos los elementos.

### PRO-E5 — C

**Evalúa:** Selección de una estructura de datos.

**Explicación:** Un diccionario o mapa representa directamente la asociación entre una clave, como el nombre, y su valor, como el precio.

## Nivel 2 — Aplicado

### PRO-A1 — A

**Evalúa:** Validación de casos límite.

**Explicación:** Una lista vacía debe tratarse de forma explícita porque no existe un promedio definido y la división usaría cantidad cero.

### PRO-A2 — C

**Evalúa:** Referencias y mutabilidad.

**Explicación:** La asignación no copia la lista; crea otro nombre para el mismo objeto, por lo que una mutación se observa desde ambos.

### PRO-A3 — B

**Evalúa:** Manejo específico de errores esperados.

**Explicación:** Conviene detectar la conversión inválida cerca de donde ocurre y comunicar suficiente contexto para tomar una decisión segura.

### PRO-A4 — B

**Evalúa:** Diseño de pruebas en límites.

**Explicación:** Probar justo antes, en y después de los límites permite detectar errores frecuentes en comparaciones inclusivas.

### PRO-A5 — A

**Evalúa:** Elección de una estructura eficiente para unicidad.

**Explicación:** Un conjunto mantiene valores únicos y evita las comparaciones repetidas entre todos los pares de elementos.

## Nivel 3 — Profundización

### PRO-P1 — C

**Evalúa:** Separación entre lógica y efectos externos.

**Explicación:** Una decisión pura recibe sus datos como entradas y produce resultados deterministas; las llamadas externas pueden probarse por separado.

### PRO-P2 — A

**Evalúa:** Riesgos del estado mutable compartido.

**Explicación:** Un contexto propio por tarea evita que trabajos superpuestos sobrescriban datos que pertenecen a otro cliente.

### PRO-P3 — B

**Evalúa:** Crecimiento y escalabilidad de algoritmos.

**Explicación:** El tiempo de X crece más lentamente en la observación disponible. Aun así, conviene confirmar el comportamiento con tamaños y datos representativos.

### PRO-P4 — C

**Evalúa:** Control de concurrencia y recursos.

**Explicación:** Un límite de concurrencia aprovecha el paralelismo sin abrir una cantidad de operaciones que sobrecargue la red o el servicio.

### PRO-P5 — A

**Evalúa:** Procesamiento incremental y uso de memoria.

**Explicación:** Procesar el archivo de forma incremental evita cargarlo completo y permite resolver la tarea usando memoria acotada.
